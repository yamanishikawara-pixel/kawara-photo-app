# Batch 4: ⑥ 表紙ウィザードモード（メモ）

## 方針
CoverPage の先頭に「ウィザードモード」トグルを追加。
ONにすると1フィールドずつ入力できる画面になる。
OFFでは従来通り全フィールドを一覧表示。

## 実装予定
- wizardMode state (boolean, localStorage で記憶)
- wizardStep state (0〜4)
- フィールド順: 工事件名 → 工事場所 → 工期 → 施工業者 → 作成年月日
- 非表示フィールドはスキップ
- 「次へ →」「← 戻る」「完了 ✓」ナビゲーション
- 各フィールドにオートフォーカス
- プログレスバー（1/5 etc.）
